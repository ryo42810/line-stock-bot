# line-stock-bot

日本株の「今日の注目株」を毎朝LINEに届け、X（旧Twitter）用の下書きと画像を作って自動投稿するbot。
GitHub Actions で毎日動く。サーバーは不要。

## できること

### 朝（毎日 6:43 JST を目標に開始）
- **注目銘柄の選定（5〜15件）**：Yahoo!ファイナンス（トップ・注目／値上がり／値下がりランキング）、TDnet（適時開示）、決算予定・優待ランキングのページを読み、AIが選ぶ
  - 分類：好材料／懸念材料／決算（今日発表）／優待（今月・来月が権利確定月）
  - 今日の決算発表予定は、JPX（日本取引所グループ）が公開している予定表（Excel）から読む
- **買い場候補👀（最大5件）**：ルールで機械的に選び、AIが注目理由を添える
  - 好材料の開示が前営業日の引け後に出たのに株価が未反応（前日比 -2〜+3%）
  - 上昇トレンド中の押し目（25日線から -5〜-15%、75日線が上向き）
  - 株価は横ばいなのに出来高が20日平均の2倍以上
  - 優待の権利確定月の1〜2ヶ月前
- **LINEのカード**：地合い（日経平均・ドル円・NYダウ・ナスダック・S&P500）＋銘柄ごとに株価・前日比・利回り（配当＋優待）・優待内容・権利付き最終日までの営業日数・出来高急増／年初来高値安値／25日線乖離
- **X下書き**（本文だけ送るのでそのままコピペできる）：平日はくじら枠（下の表）、日曜はアンケート版
  - ニュース版・買い場候補版のX投稿は、くじら枠に置き換えて止めている（`app.py` の `X_MORNING_NEWS_POSTS` を True にすると戻る）。LINEのカードは今までどおり届く

### 朝の追加機能：くじら枠（`kujira_posts.py`）
アカウントの軸（株主優待・高配当）に合わせた投稿を、平日の朝に1本出す。曜日ごとに型を替える。
| 曜日 | 型 | 中身 |
|---|---|---|
| 月 | 整理 | 権利確定が近い月の、人気の優待まとめ（3銘柄・画像付き） |
| 火 | 今日の1銘柄（優待） | 1〜2ヶ月先に権利確定する人気の優待から1銘柄（画像付き） |
| 水 | 解説 | 配当・優待の見方（8テーマを週替わり。個別の銘柄は出さない） |
| 木 | 今日の1銘柄（高配当） | 東証プライム・利回り3.5〜5.5%・時価総額1,000億円以上・配当性向10〜70%から1銘柄（画像付き） |
| 金 | 実体験 | 自分の売買・配当の記録。botでは作らず、夕方のLINEに書く型だけ送る（自動投稿しない） |

- 利回り・最低投資額・権利確定日などの数字は、Yahoo!ファイナンスの優待人気ランキング（月別）と配当利回りランキングのものをそのまま使う。AIに任せるのは言い回しだけ
- AIの文章に、材料に無い数字や銘柄が混ざっていたら、決まった型の文章に切り替える
- 「今日の1銘柄」は、同じ銘柄を45日間は出さない（`state.json` に記録）。今朝のニュース版・買い場候補版と同じ銘柄も出さない
- スプシの状況が「購入済」の銘柄を紹介するときは、投稿の最後に「※保有中の銘柄です」と書く（スプシが読めないときは付けられない）

### 朝の追加機能：ウォッチ銘柄の決算チェック（`earnings_watch.py`）
- スプシ「気になるテーマ株_一覧表」の「マスター」タブ（リンク共有・閲覧のみ）から銘柄を読む（状況が「見送り」は除く）
- 前営業日のTDnetに出た「決算短信」「業績予想の修正」「配当予想の修正」を拾い、PDFの1〜2ページ目をAIに要約させてLINEに1メッセージで送る（該当がない日は送らない）
- 要約の形：売上・営業益・経常・純利益の前年比／通期進捗率／通期予想の修正／配当の修正／一言。「購入済」の銘柄には★保有を付ける
- Variables の `WATCHLIST_SHEET_ID` が空のときは何もしない。スプシへの書き戻しはしない

### 夕方（平日 16:55 JST を目標に開始・祝日は休み）
- 朝の銘柄の当日の騰落（振り返り）
- 週の最終営業日：今週の成績（分類別・ベスト3／ワースト3）＋買い場候補の1週間後・1ヶ月後の成績
- 明日が権利付き最終日の優待銘柄のリマインド
- 明日決算の注目銘柄（JPXの決算発表予定表から。ウォッチ銘柄・最近配信した銘柄を優先。取れないときだけyfinanceで代用）
- 週の最終営業日：自分の売買・配当の記録を書くための型（LINEだけ。自動投稿しない）
- X下書き：なぜ動いたか／明日の決算予告／実績報告（週末のみ・成績グラフ画像付き）

### Xへの自動投稿
- Variables の `X_AUTO_POST` が `on` のときだけ、下書きを30分間隔で投稿する
- URL入り（料金が約13倍）・NGワード（必ず上がる等）の下書きは投稿しない
- 失敗・スキップがあったときだけLINEで知らせる

### 定時実行のずれ対策
GitHub Actionsの定時実行は、数時間遅れることが多い（2026/11の実績：朝は2〜6時間、夕方は5〜10時間遅れ）。そのため次の形にしている。
- 起動の予約を、目標の6時間前から2時間おきに4回入れる（朝 0:43／2:43／4:43／6:43、夕方 10:55／12:55／14:55／16:55）
- 目標より早く起動できた回は、目標の時刻まで待ってから動く。4時間以上早い回は何もしないで終わる
- その日の配信が済んだら `state.json` に記録し、あとの回は何もしないで終わる（二重配信しない）
- 起動が遅すぎた回（朝 8:55より後、夕方 22:00より後）は、LINEには送るが、Xには自動投稿しない
- 夕方の回が日付をまたいで起動したら、前の日の分として動く（以前は翌日の扱いになり、金曜の振り返りが「休場日」として消えていた）
- 手動実行（Run workflow）は、待たずにすぐ動く。Xにも投稿する

## ファイル
| ファイル | 役割 |
|---|---|
| `app.py` | 本体。銘柄選定・買い場候補・LINE送信・夕方の振り返り |
| `x_media.py` | X用の画像づくり（matplotlib）とXへの投稿 |
| `kujira_posts.py` | くじら枠（優待・高配当の投稿。月〜木の朝に1本） |
| `earnings_calendar.py` | 決算発表の予定日（JPXのExcel）の読み込み |
| `earnings_watch.py` | ウォッチ銘柄の決算チェック（スプシ読み込み・TDnet・決算短信PDFの要約） |
| `state.json` | その日に配信済みかどうかと、くじら枠で紹介した銘柄の記録。botが自動でコミット |
| `history.json` | 配信履歴（60日分）。振り返り・成績・同じ銘柄の配信回数制限（7日で2回まで）に使う。botが毎日自動でコミット |
| `images/` | X用の画像（14日で自動削除）。raw.githubusercontent.com のURLでLINEに添付 |
| `assets/whale.png` | 画像右上のクジラのアイコン |
| `.github/workflows/daily.yml` | 朝の実行（目標 JST 6:43。早めの予約を4回） |
| `.github/workflows/evening.yml` | 夕方の実行（目標 JST 16:55・月〜金。早めの予約を4回） |
| `.github/workflows/check.yml` | プルリクエストを出したときの動作確認（キーを使わないテストだけ） |
| `requirements.txt` | ライブラリのバージョン固定 |
| `scripts/` | 準備（フォント・ライブラリ）、記録の保存、失敗の通知 |
| `tests/` | キーや通信を使わないテスト |

## 設定
### Secrets（Settings → Secrets and variables → Actions → Secrets）
| 名前 | 用途 |
|---|---|
| `LINE_ACCESS_TOKEN` | LINE Messaging API のチャネルアクセストークン |
| `USER_ID` | LINEの送り先（自分のユーザーID） |
| `ANTHROPIC_API_KEY` | Claude API（Haiku 4.5） |
| `X_API_KEY` / `X_API_SECRET` | X のコンシューマーキー（OAuth 1.0a） |
| `X_ACCESS_TOKEN` / `X_ACCESS_TOKEN_SECRET` | X のアクセストークン（Read and write で発行したもの） |

### Variables（同じ画面の Variables タブ）
| 名前 | 用途 |
|---|---|
| `X_AUTO_POST` | `on` で X に自動投稿。止めるときは `off` |
| `IMAGE_THEME` | 画像の配色。空ならミッドナイト×金（noteと同じ）。前の白いカードに戻すなら `gold_solid` |
| `WATCHLIST_SHEET_ID` | ウォッチ銘柄のスプシのID（URLの `/d/` と `/edit` の間）。スプシは「リンクを知っている全員が閲覧可」にしておく |

### コード内の主な設定
- AIモデル：`claude-haiku-4-5`（Web検索は使わない）
- 画像の配色：`IMAGE_THEME`（初期値 `midnight`＝ミッドナイト×金・明朝体の題字。noteの画像とそろえている）
- 目標の時刻と、Xを見送る時刻：`TARGET_TIME` / `X_DEADLINE`（`app.py`）
- くじら枠の曜日割り・ハッシュタグ・高配当の条件：`PLAN` / `HASHTAGS` / `HAITO_*`（`kujira_posts.py`）
- Xの投稿間隔：`X_POST_INTERVAL_MIN = 30`
- Xのハッシュタグ：`X_HASHTAGS_MORNING`（朝）／`X_HASHTAGS_EVENING`（夕方。#朝活なし）

## 手動で動かす
Actions → **Daily Stock Bot**（朝）または **Evening Review**（夕方）→ Run workflow

## 料金の目安
- Claude API：朝 月400円前後＋夕方 月15〜100円（ログの「API料金（推定）」で確認できる）
- X API：従量課金。普通の投稿 $0.015／件、URL付き $0.20／件（URLは入れない運用）。くじら枠で週4本増える
- GitHub Actions：公開リポジトリなので、待ち時間が長くても無料

## 取得できないサイト
GitHub Actions からは、みんかぶ（403）と株探（405）がブロックされるため使っていない。
