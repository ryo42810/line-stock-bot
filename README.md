# line-stock-bot

日本株の「今日の注目株」を毎朝LINEに届け、X（旧Twitter）用の下書きと画像を作って自動投稿するbot。
GitHub Actions で毎日動く。サーバーは不要。

## できること

### 朝（毎日 6:43 JST 開始）
- **注目銘柄の選定（5〜15件）**：Yahoo!ファイナンス（トップ・注目／値上がり／値下がりランキング）、TDnet（適時開示）、決算予定・優待ランキングのページを読み、AIが選ぶ
  - 分類：好材料／懸念材料／決算（今日発表）／優待（今月・来月が権利確定月）
- **買い場候補👀（最大5件）**：ルールで機械的に選び、AIが注目理由を添える
  - 好材料の開示が前営業日の引け後に出たのに株価が未反応（前日比 -2〜+3%）
  - 上昇トレンド中の押し目（25日線から -5〜-15%、75日線が上向き）
  - 株価は横ばいなのに出来高が20日平均の2倍以上
  - 優待の権利確定月の1〜2ヶ月前
- **LINEのカード**：地合い（日経平均・ドル円・NYダウ・ナスダック・S&P500）＋銘柄ごとに株価・前日比・利回り（配当＋優待）・優待内容・権利付き最終日までの営業日数・出来高急増／年初来高値安値／25日線乖離
- **X下書き**（本文だけ送るのでそのままコピペできる）：ニュース版・買い場候補版（銘柄は重複させない）、日曜はアンケート版
- **X用の画像**：ニュース版・買い場候補版に銘柄カード画像を付ける

### 夕方（平日 16:55 JST 開始・祝日は休み）
- 朝の銘柄の当日の騰落（振り返り）
- 週の最終営業日：今週の成績（分類別・ベスト3／ワースト3）＋買い場候補の1週間後・1ヶ月後の成績
- 明日が権利付き最終日の優待銘柄のリマインド
- 明日決算の注目銘柄（yfinanceの決算予定日で判定）
- X下書き：なぜ動いたか／明日の決算予告／実績報告（週末のみ・成績グラフ画像付き）

### Xへの自動投稿
- Variables の `X_AUTO_POST` が `on` のときだけ、下書きを30分間隔で投稿する
- URL入り（料金が約13倍）・NGワード（必ず上がる等）の下書きは投稿しない
- 失敗・スキップがあったときだけLINEで知らせる

## ファイル
| ファイル | 役割 |
|---|---|
| `app.py` | 本体。銘柄選定・買い場候補・LINE送信・夕方の振り返り |
| `x_media.py` | X用の画像づくり（matplotlib）とXへの投稿 |
| `history.json` | 配信履歴（60日分）。振り返り・成績・同じ銘柄の配信回数制限（7日で2回まで）に使う。botが毎日自動でコミット |
| `images/` | X用の画像（14日で自動削除）。raw.githubusercontent.com のURLでLINEに添付 |
| `assets/whale.png` | 画像右上のクジラのアイコン |
| `.github/workflows/daily.yml` | 朝の実行（cron `43 21 * * *` = JST 6:43） |
| `.github/workflows/evening.yml` | 夕方の実行（cron `55 7 * * 1-5` = JST 16:55） |

## 設定
### Secrets（Settings → Secrets and variables → Actions → Secrets）
| 名前 | 用途 |
|---|---|
| `LINE_ACCESS_TOKEN` | LINE Messaging API のチャネルアクセストークン |
| `USER_ID` | LINEの送り先（自分のユーザーID） |
| `ANTHROPIC_API_KEY` | Claude API（Haiku 4.5） |
| `X_API_KEY` / `X_API_SECRET` | X のコンシューマーキー（OAuth 1.0a） |
| `X_ACCESS_TOKEN` / `X_ACCESS_TOKEN_SECRET` | X のアクセストークン（Read and write で発行したもの） |

### Variables（同じ画面の Variables タブ）
| 名前 | 用途 |
|---|---|
| `X_AUTO_POST` | `on` で X に自動投稿。止めるときは `off` |

### コード内の主な設定
- AIモデル：`claude-haiku-4-5`（Web検索は使わない）
- 画像の配色：`IMAGE_THEME`（初期値 `gold_solid`＝ネイビー×ゴールドのベタ塗り）
- Xの投稿間隔：`X_POST_INTERVAL_MIN = 30`
- Xのハッシュタグ：`X_HASHTAGS_MORNING`（朝）／`X_HASHTAGS_EVENING`（夕方。#朝活なし）

## 手動で動かす
Actions → **Daily Stock Bot**（朝）または **Evening Review**（夕方）→ Run workflow

## 料金の目安
- Claude API：朝 月400円前後＋夕方 月15〜100円（ログの「API料金（推定）」で確認できる）
- X API：従量課金。普通の投稿 $0.015／件、URL付き $0.20／件（URLは入れない運用）

## 取得できないサイト
GitHub Actions からは、みんかぶ（403）と株探（405）がブロックされるため使っていない。
